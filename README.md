# One Line of Earned Pride

Entry for the make.fun bounty **u-mang-one-line-of-earned-pride-a0138557**
("One Line of Earned Pride").

`main.ts` is a self-contained Node program: it writes the entry line to
`/output/entry.txt`, deterministically — the same bytes on every run,
no network, no clock, no randomness.

The line:

> He practised the same piano piece every night after his shift for a year, and at his daughter's recital he finally played it without looking at his hands.
